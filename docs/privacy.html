FloorChat 개인정보처리방침

FloorChat은 Google 계정으로 로그인하고 화면 아래 캐릭터를 통해 공용 채팅을 이용하는 Windows 앱입니다.

처리하는 정보와 목적 - Google 로그인 과정에서 계정 식별자, 이메일 및 Google이 제공하는 기본 프로필 정보를 Supabase 인증 서비스에서 처리합니다. Google 비밀번호는 FloorChat이 수집하지 않습니다. - 닉네임과 캐릭터, 최초 채팅 참여 시각, 메시지 내용 및 전송 시각을 계정 확인, 채팅 제공과 기록 조회를 위해 저장합니다. - 접속 중인 사용자의 닉네임·캐릭터와 접속 상태를 실시간으로 공유합니다. 앱은 로그인 세션을 기기에 저장하여 다음 실행에도 로그인을 유지합니다.

다른 사용자에게 보이는 정보 모든 이용자는 하나의 공용 채팅방을 이용합니다. 메시지 내용, 작성자의 닉네임과 캐릭터, 전송 시각이 해당 메시지를 볼 수 있는 다른 로그인 사용자에게 표시됩니다. 새 사용자는 최초 참여 시점 이후의 메시지만 조회합니다. 최초 참여 이후의 메시지는 재접속해도 조회할 수 있으므로 비밀 정보나 타인의 개인정보를 보내지 마세요. 이 조회 제한은 과거 메시지가 서버에서 삭제된다는 의미가 아닙니다.

저장 및 외부 서비스 인증과 채팅 데이터는 Supabase 프로젝트에 저장됩니다. 프로젝트 데이터베이스 지역은 대한민국 서울로 설정되어 있습니다. Google은 로그인 제공자로, GitHub는 앱 다운로드와 업데이트 배포에 사용됩니다. 각 제공업체가 처리하는 접속·서비스 데이터에는 해당 업체의 정책이 적용됩니다. Google 계정 데이터는 로그인과 계정 식별에 사용하며 광고 판매 목적으로 이용하지 않습니다.

보관 및 삭제 채팅 메시지는 전송 시각부터 10시간 동안 조회할 수 있으며, 1분마다 실행되는 서버 작업이 만료된 메시지를 삭제합니다. 작업이 정상 실행되는 동안 실제 삭제까지 최대 약 1분이 추가될 수 있고, 서버 중단·장애 시 삭제가 지연될 수 있습니다. 계정, 프로필과 최초 참여 시각은 채팅 만료와 별도로 보관됩니다. 앱 삭제나 로그아웃만으로 계정 정보가 삭제되지는 않습니다. 계정·개인정보 삭제 요청은 아래 이메일로 보내 주세요. 운영자가 본인과 대상을 확인한 뒤 직접 처리합니다. 다른 사용자가 별도로 복사하거나 캡처한 내용은 서버 삭제로 회수할 수 없습니다.
